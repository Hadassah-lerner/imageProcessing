# תרגיל 10 - מסכות בוליאניות

## 1. ספירת פיקסלים בהירים וכהים

אחרי המרת התמונה לגווני אפור, הביטוי `gray > 200` יוצר מסכה בוליאנית שבה `True` מסמן פיקסל בהיר מ-200.

סכום המסכה מחזיר את מספר הפיקסלים המתאימים. באופן דומה, `gray < 50` סופר את הפיקסלים הכהים מ-50.

```python
bright_count = (gray > 200).sum()
dark_count = (gray < 50).sum()
```

## 2. יצירת תמונה בשחור ולבן בלבד

בשתי השיטות מתקבל מערך שבו כל פיקסל הוא רק `0` או `255`.

### דרך 1 - השמה עם מסכה

```python
binary_mask = np.zeros_like(gray)

mask = gray > 128
binary_mask[mask] = 255
```

### דרך 2 - שימוש ב-`np.where`

```python
binary_where = np.where(
    gray > 128,
    255,
    0
).astype(np.uint8)
```

## 3. צביעת פיקסלים בהירים באדום

המסכה היא דו-ממדית בגודל `(H, W)`, בדיוק כמו התמונה בגווני אפור. אפשר להשתמש בה ישירות כדי לבחור פיקסלים במערך הצבעוני בגודל `(H, W, 3)`.

מאחר ש-OpenCV משתמש ב-BGR, הצבע האדום נכתב כ-`[0, 0, 255]`.

```python
bright_mask = gray > 200

red_result = img.copy()
red_result[bright_mask] = [0, 0, 255]
```

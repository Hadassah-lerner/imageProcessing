# תרגיל 7 - חיתוכים

## 1. תיאור הביטויים וה-shape

| ביטוי | מה הוא מחזיר |
|---|---|
| `img[10, 20]` | פיקסל יחיד בשורה 10 ובעמודה 20. בתמונה צבעונית מתקבל מערך באורך 3: B, G, R. |
| `img[:, :, 0]` | ערוץ B (כחול) בלבד. מתקבלת תמונה דו-ממדית בגודל H×W. |
| `img[100:200, 50:150]` | חיתוך של התמונה: 100 שורות ו-100 עמודות, כלומר אזור בגודל 100×100×3, אם התמונה גדולה מספיק. |
| `img[::2, ::2]` | כל שורה שנייה וכל עמודה שנייה. מתקבלת תמונה מוקטנת בערך לחצי בגובה ולחצי ברוחב. |
| `img[::-1, :]` | כל השורות בסדר הפוך. מתקבלת תמונה הפוכה מלמעלה למטה (upside down). |
| `img[:, ::-1, :]` | כל העמודות בסדר הפוך. מתקבלת תמונת מראה אופקית (mirror). |
| `img[0]` | השורה הראשונה של התמונה. בתמונה צבעונית מתקבל מערך בגודל W×3. |
| `img[:, 0]` | העמודה הראשונה של התמונה. בתמונה צבעונית מתקבל מערך בגודל H×3. |

## 2. View לעומת copy

במקרה הראשון, `crop` הוא **view** של המערך `a`. לכן `crop[:] = 9` משנה גם את `a` המקורי. לאחר ההשמה, ארבעת התאים שבאזור `a[1:3, 1:3]` יהיו שווים ל-9.

```python
a = np.zeros((4, 4), dtype=np.uint8)
crop = a[1:3, 1:3]
crop[:] = 9
print(a)
```

במקרה השני, `.copy()` יוצר מערך חדש ונפרד. לכן השינוי ב-`crop2` אינו משנה את `b`. במקרה זה `b` נשאר כולו אפסים.

```python
b = np.zeros((4, 4), dtype=np.uint8)
crop2 = b[1:3, 1:3].copy()
crop2[:] = 9
print(b)
```

## 3. מסגרת שחורה

המסגרת נוצרת על עותק של התמונה בעזרת ארבע השמות של slices. כל השמה בוחרת פס ברוחב 10 פיקסלים ומציבה בו `0`. מכיוון שהתמונה היא `uint8`, הערך `0` מייצג שחור.

```python
framed = img.copy()
framed[:10, :] = 0
framed[-10:, :] = 0
framed[:, :10] = 0
framed[:, -10:] = 0
```
